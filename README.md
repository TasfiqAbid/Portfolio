# Galib Tasfiq Abid — Portfolio

Personal portfolio website showcasing creative direction, visual design, and frontend engineering. Built with Next.js (App Router), Three.js, GSAP, and Tailwind CSS.

## Tech Stack

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Language**: TypeScript, React 19
- **3D & Graphics**: Three.js, React Three Fiber, Drei
- **Animation**: GSAP 3, ScrollTrigger
- **Smooth Scroll**: Lenis
- **Styling**: Tailwind CSS v4, Vanilla CSS
- **Typography**: Inter, Playfair Display, Pacifico, Geist Mono (`next/font/google`)

## Key Features

- **Interactive 3D Visuals**: Real-time metallic Torus Knot reacting to cursor position and scroll progression.
- **Scroll-Driven Hero**: Pinning sequence with horizontal text reveal and smooth unpin transitions.
- **Filmstrip Work Carousel**: Momentum-based interactive project showcase with drag and wheel support.
- **OKLAB Color Transitions**: Mathematically smooth background theme transitions between sections.
- **Kinetic Micro-Interactions**: Custom magnetic buttons, text roll-ups, and interactive cursor elements.
- **Responsive Layout**: Designed for seamless presentation across desktop, tablet, and mobile displays.

## Getting Started

### Prerequisites

- Node.js 20.x or later
- npm 10.x or later

### Installation & Development

```bash
# Clone the repository
git clone https://github.com/TasfiqAbid/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build & Production

```bash
# Type check
npx tsc --noEmit

# Lint check
npm run lint

# Generate production build
npm run build

# Start production server
npm run start
```
